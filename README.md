# ⚡ Neon Audio Player (Киберпанк Аудиоплеер для телефона и ПК)

Современный локальный аудиоплеер с темной неоновой эстетикой, адаптивным мобильным интерфейсом, поддержкой PWA, Drag-and-Drop плейлистом, 10-полосным эквалайзером и реактивным Canvas-визуализатором спектра.

---

## ✨ Основные возможности

### 📱 Оптимизировано для телефонов (Mobile First):
* **PWA & Offline:** Работает автономно без подключения к интернету. Можно установить на домашний экран смартфона как нативное приложение.
* **MediaSession API:** Интеграция с шторкой уведомлений, экраном блокировки смартфона и Bluetooth-наушниками (обложка, название трека, артист, перемотка, кнопки play/pause/prev/next).
* **Сенсорный Drag-and-Drop:** Полноценное перетаскивание треков пальцем за маркер `⋮⋮` с виброоткликом (Haptic Feedback) + кнопки `▲ / ▼`.
* **Таймер сна:** Автоматическая остановка воспроизведения через 15, 30, 45 или 60 минут.

### 🎨 Темная неоновая эстетика (Dark Neon Theme):
* Глубокий темный фон (`#08090f`, `#0f111d`) для OLED-экранов телефонов.
* Неоновые акценты (Electric Cyan `#00f2ff`, Neon Pink `#ff007f`, Purple `#a855f7`).
* 4 переключаемые цветовые схемы:
  * **Cyber Cyan & Pink** (классический киберпанк)
  * **Synthwave Sunset** (ретро-закат: оранжевый + фиолетовый)
  * **Matrix Emerald** (неоновый зеленый)
  * **Laser Deep Blue** (ультрамарин + электрик)
* Реактивная пульсация обложки в такт басам (Sub-bass pulse).

### 🎚️ Кастомный 10-полосный эквалайзер:
* **10 полос частот:** 32 Гц, 64 Гц, 125 Гц, 250 Гц, 500 Гц, 1 кГц, 2 кГц, 4 кГц, 8 кГц, 16 кГц (диапазон от -12 dB до +12 dB).
* **Bass Boost:** Резонансный НЧ-фильтр усиления глубокого баса (до +15 dB).
* **Preamp Gain:** Предусилитель сигнала от -6 dB до +6 dB.
* **10 пресетов в один клик:** Flat, Bass Boost, Cyberpunk EDM, Synthwave, Rock, Pop, Hip-Hop, Techno, Jazz, Vocal Boost.
* **Bypass switch:** Мгновенное A/B сравнение с чистым звуком.

### ⚡ Реактивный Canvas-визуализатор спектра (60 FPS):
* **4 визуальных режима:**
  1. **⚡ Столбики (Cyber Bars):** Неоновые градиентные столбцы с физикой падающих пиков (Peak Hold) и отражением.
  2. **⭕ Круговой (Radial Pulse):** Радиальный спектр вокруг светящегося центра, пульсирующий в ритме трека.
  3. **〰️ Волна (Laser Oscilloscope):** Многослойный лазерный осциллограф с эффектом неонового свечения.
  4. **✨ Взрыв (Starburst Particles):** Кибер-частицы и взрывные волны от ударов бас-бочки.
* Регулировка чувствительности и масштабирование под Retina/OLED дисплеи (`devicePixelRatio`).

### 🎵 Локальный плейлист и ID3-теги:
* **100% приватность:** Аудиофайлы не загружаются на сервер, декодируются прямо в браузере.
* **Встроенный ID3v2 парсер:** Извлекает название, исполнителя, альбом и вшитую обложку (APIC frame).
* **Генератор неоновых обложек:** Если у файла нет обложки, генерируется стильный киберпанк-арт в SVG.
* **Встроенный демо-синтезатор:** Кнопка «Синтезировать демо» мгновенно создает 16-секундный стерео WAV-трек в стиле Synthwave 124 BPM для мгновенной проверки звука без файлов!
* Поддержка форматов: MP3, FLAC, WAV, OGG, AAC, M4A, WEBM.

## 🚀 Как запустить на телефоне

### Вариант 1: Через локальный Wi-Fi (самый простой)
1. Убедитесь, что компьютер и телефон подключены к одной Wi-Fi сети.
2. Дважды кликните по файлу **`start-player.bat`** (или выполните в PowerShell `.\start-server.ps1`).
3. Скрипт покажет адрес для телефона, например:
   ```
   http://192.168.1.105:8080/
   ```
4. Откройте эту ссылку в браузере на телефоне (Chrome / Safari / Firefox).
5. **Установите как приложение (PWA):**
   * **Android (Chrome):** Нажмите меню (3 точки) → *«Установить приложение»* или *«Добавить на главный экран»*.
   * **iOS (Safari):** Нажмите кнопку *«Поделиться»* (квадрат со стрелкой вверх) → *«На экран „Домой“»*.

### Вариант 2: Запуск без сервера (на ПК)
* Просто откройте файл `index.html` в браузере Edge, Chrome, Firefox или Safari. Все функции плеера, эквалайзера и визуализатора работают напрямую!

## 📦 Как получить APK для Android (100% Офлайн)

Все исходники для создания нативного Android-приложения уже подготовлены в папке `android/`. Все файлы плеера вшиты внутрь приложения (`assets/`), поэтому оно работает **полностью автономно без интернета**.

### 🌟 4 простых способа получить APK:

#### 1. В 1 клик через онлайн-генератор (самый быстрый способ):
* В папке проекта уже создан готовый архив **[`neon-player-offline-bundle.zip`](./neon-player-offline-bundle.zip)** (53 КБ).
* Откройте любой бесплатный сервис упаковки (например, [WebToApp](https://www.webtoapp.design/) или [AppsGeyser](https://appsgeyser.com/) в режиме «HTML App / ZIP»).
* Загрузите этот ZIP-архив и нажмите «Собрать APK» — сервис скомпилирует готовый `.apk` за 30 секунд.

#### 2. Бесплатная автосборка через GitHub Actions (без установки SDK на ПК):
* В репозитории уже настроен готовый скрипт [`.github/workflows/build-apk.yml`](./.github/workflows/build-apk.yml).
* Опубликуйте проект на GitHub. Во вкладке **Actions** автоматически запустится сборка на серверах GitHub (с Ubuntu и Android SDK).
* Через 1 минуту в разделе «Artifacts» появится ссылка на скачивание `NeonAudioPlayer-APK` (`app-debug.apk`).

#### 3. Сборка в Android Studio:
1. Запустите Android Studio и выберите `Open Project` → укажите папку `neon-audio-player/android`.
2. В верхнем меню выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
3. Готовый APK появится по пути:
   `android/app/build/outputs/apk/debug/app-debug.apk`.

#### 4. Встроенный нативный WebAPK (без сторонних утилит):
* На Android функция Chrome «Установить приложение» (Install App) на самом деле компилирует и регистрирует в системе настоящий **WebAPK**.
* Приложение получает собственную иконку в меню смартфона, запускается в полноэкранном режиме и работает 100% офлайн благодаря встроенному Service Worker.

## 📂 Структура проекта

```
neon-audio-player/
├── index.html               # Главная разметка и интерфейс табов
├── manifest.webmanifest     # Манифест PWA (установка на экран телефона)
├── sw.js                    # Service Worker для офлайн-кеширования
├── icon.svg                 # Неоновая векторная иконка приложения
├── start-player.bat         # 1-клик запуск для Windows
├── start-server.ps1         # Локальный HTTP-сервер с определением IP
├── README.md                # Руководство
├── css/
│   └── style.css            # Неоновая тема, адаптивные стили для мобильных
└── js/
    ├── app.js               # Главный контроллер интерфейса
    ├── audio-engine.js      # Web Audio API (10-полосный EQ, Bass Boost, Preamp, Analyser)
    ├── visualizer.js        # Canvas-визуализатор 60 FPS (4 режима)
    ├── playlist.js          # Плейлист, Drag-and-Drop (Desktop + Touch), Shuffle, Repeat
```
