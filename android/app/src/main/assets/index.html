📱 Как использовать на телефоне

1
Локальная сеть (Wi-Fi): Запустите скрипт start-server.ps1 на компьютере и откройте выведенный IP-адрес в браузере телефона (например, http://192.168.1.x:8080).
2
Добавить на главный экран (PWA): В браузере телефона нажмите «Поделиться» / меню (три точки) → «На экран Домой». Плеер установится как отдельное приложение с иконкой и офлайн-режимом!
3
Управление с экрана блокировки: Плеер поддерживает MediaSession API — название трека, обложка и кнопки воспроизведения отображаются в шторке уведомлений и на заблокированном экране телефона.
4
Drag-and-Drop на телефоне: Удерживайте трек пальцем за маркер ⋮⋮ и перемещайте вверх или вниз для изменения порядка. Также есть удобные стрелки ▲ / ▼.
